# Zekai Shi — Academic Profile

React and Vite source for [zekaishi.github.io](https://zekaishi.github.io/).

## Content updates

Edit the JSON files in `src/content/`, commit, and push to `main`. The deployment workflow builds hashed production assets and publishes them to `gh-pages` automatically.

## Local development

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```
